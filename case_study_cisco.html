Stakeholders said it worked for Splunk. I still needed to know if it worked for people trying to find a demo.

Findability, v2 · Hackathon → proposal

The copy button was a beginning, not an end.

Developers landed on technical blogs, copied a code snippet, and left. Everyone treated copy as the end of the journey. I treated it as a high-intent signal, and explored it through an org hackathon.

Old vs. new. Clearer hierarchy, an explicit “Copy,” and built to be maintained.

The question I started from

What if copying a snippet opened a door deeper into the ecosystem, uniquely for each user? The tutorial, doc, or guide that matches what they just grabbed, not a generic list of related links.

The concept: copy a snippet, get an AI-curated next step.

Pressure-testing with SMEs

Before writing the proposal, I asked subject matter experts what the backend would actually have to do.

01

What signals could power it?Snippet interactions, site behavior, and user context.

02

What would the AI need?APIs, storage, latency, and backend load.

03

What was realistic first?Contextual resources now, personalization as infrastructure matured.

The call

I deprioritized the personalization layer. Tracking user history across the backend was heavy effort for an uncertain payoff, while the snippet redesign was a quick win. So I scoped the work to the component, documented the full concept with SME findings and specs, and left it with the team when my internship ended.

6 / 6

Concept testing

Every participant said they’d want this. One change came out of it: making copy explicit with the word “Copy” instead of an icon alone.

Visual specs: anatomy, type scale, and spacing for engineering handoff.

Interaction specs: default, hover, copied, and AI-suggestion states, so nothing is ambiguous in the build.

What I’d refine now

I was newer to designing for AI trust then. Today, I’d make the reasoning behind each recommendation clearer, add stronger user controls, and test how much personalization developers actually want in a technical workflow.

Reflection

What I’d do differently.

This internship taught me how to create momentum inside a large organization, including teaching a Figma Make workshop on the AI-assisted workflow I’d used all summer.

01

Clarity compounds.My highest-leverage work made the system legible: an audit six teams could plan from, and one front door for every demo. Next time, I’d look for that leverage earlier.

02

Evidence moves decisions.Session recordings, usability tests, and competitor patterns beat any opinion. When I could show a user struggling, the debate ended.

03

Name the tool, own the judgment.Claude Code built my audit matrix and Figma Make sped up explorations, but every rubric, placement, and final call was mine.
